01 how it reads

a tiny cpu for every line.

Real processors fetch an instruction, decode it, then execute it. codeart does the same for your Python, so cause and effect are never more than one step apart.

  1. fetch

    find the line

    The editor highlights exactly which line runs next: loops, branches and function calls included.

  2. decode

    say what it means

    Plain-English operations: APPEND 7 → end of nums, SWAP arr[0] ⇄ arr[1], need in seen → True.

  3. execute

    watch memory change

    Blocks drop into lists, hop when swapped and fly into variables. Stack frames pile up and pop. Scrub backwards any time, and move the camera wherever you like.
